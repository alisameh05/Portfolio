# Consent-first measurement and conservative retention

Status: accepted

Non-essential Public event data is collected only after Visitor consent, independently of the purpose-limited functional identity created when a Visitor reacts or rates. Raw events are retained for 14 days and daily aggregates for 13 months; rejected or unresolved Feedback is retained for 90 days and suppressed Feedback history for 12 months unless a governing deletion requirement shortens those periods.

**Consequences**: Reports accept incomplete samples, preserve Low-sample states, and never use names, Feedback text, CV contents, access secrets, or raw direct identifiers as measurement dimensions.
