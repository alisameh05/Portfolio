# Measurable public quality gates

Status: accepted

The public portfolio and owner workspace must target WCAG 2.2 AA for their core journeys, be tested on real devices using Core Web Vitals-style measures, and progressively load rich media and immersive effects without blocking core content. Published content should remain usable from its last valid state when CMS, analytics, or external destinations fail; operational alerts are reserved for actionable failures.

**Consequences**: Accessibility, resilience, and performance are release requirements that can block publication or release readiness; visual polish cannot override them.
