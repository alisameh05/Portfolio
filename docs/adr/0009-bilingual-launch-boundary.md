# Bilingual launch boundary

Status: accepted

The first release supports English and Arabic with full right-to-left behavior in the Arabic experience. Each language version requires owner review and explicit publication; machine translation may assist drafting but cannot publish automatically. Arabic may reuse English media, but external links and CV access remain English-only until localized versions exist.

**Consequences**: The Arabic experience is intentionally asymmetric at launch and must communicate unavailable localized capabilities truthfully rather than presenting English-only destinations as localized content.
