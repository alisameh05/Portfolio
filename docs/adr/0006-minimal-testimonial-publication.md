# Minimal testimonial publication

Status: accepted

The initial product permits a testimonial to be published when the owner has a stored name and quote, without requiring a separate permission record or relationship verification. Public presentation must remain limited to that stored text and must not imply a verified source, relationship, or endorsement beyond it. This is an intentional simplification of the evidence model for testimonials and does not change the stronger evidence requirements for project claims, outcomes, media, or achievements.

**Consequences**: Testimonials carry less provenance assurance than other evidence types, so the public UI must avoid verification language and the owner can later suppress an approved testimonial while retaining its moderation history.
