# Durable public identity and safe media

Status: accepted

Published pages receive durable public identity: title or slug changes preserve prior routes through redirects and canonical metadata, while draft previews remain private and non-indexable. Public media and CV files are treated as untrusted inputs until validated, safely processed, given required accessibility metadata, and explicitly accepted for publication.

**Consequences**: Shared recruiter links remain useful over time, and media or CV uploads cannot cross the admin/public boundary merely because a file was uploaded.
