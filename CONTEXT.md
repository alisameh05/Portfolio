# ShipWithAli Portfolio Context

ShipWithAli is a recruiter-first portfolio and owner-operated publishing workspace for AI/ML product work. This glossary defines the shared language used across its public experience, owner workspace, and product documentation.

## Portfolio content

**Project**:
A portfolio item that explains what was built, the problem it addresses, the owner's contribution, and the evidence supporting its claims.

**Case study**:
The structured account of a Project's summary, problem, owner role, contributions, outcomes, lessons, media, and destinations.
_Avoid_: Project description, project page

**Lab entry**:
A content item for an experiment, research exploration, incomplete idea, or work in progress that is intentionally distinct from a Project.
_Avoid_: Unfinished project, draft project

**Achievement**:
A career or learning milestone such as a launch, competition, certification, academic result, professional milestone, open-source contribution, or award.
_Avoid_: Timeline item

**Testimonial**:
A name-and-quote entry associated with either a Project or the general profile. It does not imply verified permission, relationship, or endorsement beyond the stored text.
_Avoid_: Verified endorsement

**Timeline**:
The public chronological record of Achievements, presented oldest-to-newest so a visitor can follow the owner's development.

**Project relationship**:
An owner-curated association between two Projects that makes each eligible to appear as related to the other.
_Avoid_: Automatic recommendation

**External link**:
A Project-associated destination with a type, public label, destination, optional description, and truthful availability state.
_Avoid_: Contact channel

**Contact channel**:
An owner-configured way for a visitor to contact or follow the owner, such as LinkedIn, WhatsApp, Instagram, or phone.
_Avoid_: External link

**Global project CTA**:
The single owner-configured call-to-action used consistently across Project case studies, with a safe fallback when its destination is unavailable.
_Avoid_: Per-project CTA

## Classification

**Taxonomy**:
An owner-managed controlled vocabulary used to classify Projects by category, AI/ML domain, technology, or project type.
_Avoid_: Tag list, free-form tags

**Taxonomy value**:
A named, reusable value within a Taxonomy. A retired value remains part of historical classification but cannot receive new assignments.
_Avoid_: Tag

**Project status**:
An owner-defined maturity or work-state label for a Project, such as Shipped, Active, In Progress, Experimental, Research, or Open Source.
_Avoid_: Lifecycle state, publication state, Archived

**Featured**:
An independent presentation flag that gives a Project editorial emphasis without changing whether it is publicly visible.
_Avoid_: Lifecycle state, project status

## Publishing and evidence

**Publishable content**:
A Project, Lab entry, Achievement, Testimonial, or Media asset whose public visibility is controlled by the owner.

**Public lifecycle**:
The content-wide visibility progression through Draft, Published, Hidden, and Archived. It is independent of Project status and the Featured flag.
_Avoid_: Project status, moderation state

**Draft**:
Publishable content being prepared that has never been made publicly discoverable.

**Published**:
The sole Public lifecycle state eligible for public discovery. Localized content also requires an explicitly published Language version before visitors can encounter it.

**Hidden**:
Previously managed Publishable content intentionally removed from normal public discovery without being treated as deleted or historical.

**Archived**:
Retained historical Publishable content excluded from normal public discovery together with its related public presentation.
_Avoid_: Archived project status

**Revision**:
An immutable saved version of editable content in one Localized revision stream. Creating a Revision does not make it public.
_Avoid_: Draft project

**Localized revision stream**:
The ordered Revisions for one Publishable content item in one language, with at most one Revision designated as currently published.
_Avoid_: Translation record

**Language version**:
An independently reviewed and explicitly published language representation of public content. Machine translation may assist preparation but cannot publish a Language version automatically.
_Avoid_: Automatic translation

**Publication**:
The owner's explicit decision to make one reviewed Revision the current public Language version of Published content.
_Avoid_: Save, upload

**Evidence package**:
The editorial collection of public claims, Supporting artifacts, and Evidence states required to substantiate a Project or Achievement.
_Avoid_: Media gallery

**Supporting artifact**:
A source, document, result, Media asset, or destination offered in support of a public claim.
_Avoid_: Decorative media

**Evidence state**:
An internal editorial assessment of whether a public claim and its Supporting artifacts have been checked. It is not an external certification or public badge.
_Avoid_: Verification badge

## Routes and media

**Public route identity**:
The durable public identity assigned to a published page independently of its current title or slug.
_Avoid_: Slug

**Public route redirect**:
A durable mapping from a former public route to the current canonical route for the same Public route identity.
_Avoid_: Alias

**Media asset**:
An owner-managed image, video, document, or other file that must be accepted for public use independently of being uploaded.
_Avoid_: Upload

**Media accessibility metadata**:
The approved non-visual description or decorative classification required for an image, plus the caption or summary required for meaningful video.
_Avoid_: Filename, upload description

## Language and quality

**Arabic experience**:
The right-to-left public experience whose content requires independent owner review. It may reuse English Media assets, while English-only destinations must remain truthfully identified as unavailable in Arabic.

**Core public journey**:
The visitor path through the landing page, Project discovery, case-study reading, CV access where available, and a contact action.

**Operational alert**:
A notification for an actionable security, publication, recovery, integration, or analytics-pipeline failure. Routine healthy activity is not alert-worthy.

## Visitor interaction

**Visitor**:
A person using the public portfolio without a required account.

**Reaction**:
A Visitor's like or dislike for a Project, limited to one current choice per Visitor and Project.

**Rating**:
A Visitor's one-to-five-star assessment of a Project, limited to one current value per Visitor and Project.

**Feedback**:
Written Visitor commentary containing a name and paragraph that enters Moderation before possible public display.
_Avoid_: Testimonial

**Moderation**:
The owner's review process for deciding whether submitted Feedback may be displayed publicly.

**Moderation decision**:
An owner-recorded approval, rejection, or later suppression of Feedback that preserves the review history.
_Avoid_: Feedback deletion

## Administration and measurement

**Owner**:
The authenticated person who operates the portfolio, manages content, moderates Feedback, activates CV versions, and configures Analytics goals.
_Avoid_: Admin user, editor

**CV version**:
An accepted snapshot of the owner's curriculum vitae retained as part of the portfolio's administrative history.
_Avoid_: CV upload

**Current CV**:
The single CV version designated as publicly viewable and downloadable. Earlier CV versions remain retained unless a Retention policy requires otherwise.
_Avoid_: Latest upload

**Analytics goal**:
An owner-defined, versioned measurement rule over existing Visitor actions or event sequences, optionally scoped to pages or Projects. It does not alter the Visitor experience.
_Avoid_: Conversion cause

**Visitor measurement identity**:
A privacy-preserving pseudonymous signal used only when needed to distinguish unique and returning Visitor patterns. It is not an account or directly identifying Visitor record.
_Avoid_: Visitor account, user profile

**Public event data**:
Privacy-minimized measurement data retained only at the detail and duration needed for portfolio decisions, with aggregate reporting preferred.

**Journey context**:
The sequence of relevant pages, Projects, and actions preceding a measured conversion. It provides context without asserting that one item caused the outcome.
_Avoid_: Attribution proof

**Engagement estimate**:
An approximate active-attention signal derived from Visitor interaction, not an exact measure of reading time.
_Avoid_: Reading time

**Low-sample state**:
A public or owner-facing presentation that exposes limited observation counts so averages and aggregates are not mistaken for strong evidence.

**Retention policy**:
The documented rule for how long Feedback and Public event data remain available, including when records may be deleted or anonymized.

**Owner export**:
A documented, usable package of the owner's portfolio content and operational records, subject to privacy and Retention policy rules.
_Avoid_: Database backup
